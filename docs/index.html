틈타는 이런 앱이에요

  • 도착할 시각과 중간 역에서 머무를 시간을 고르면, 출발역에서 늦어도 몇 시 열차를 타야 하는지 알려 줘요.
  • 탈 열차, 들를 역에서 다시 탈 열차, 도착 시각까지 동선으로 보여 줘요.
  • 일반열차 시간표 기준이에요. 실시간 지연은 반영하지 않아요.

데이터 출처: 국토교통부 (TAGO) 지하철정보, 공공데이터포털. 틈타는 정부·철도 운영기관과 관계없는 개인 프로젝트예요.
